# 界面风格参考

检索和阅读日期：2026-10-07。以下是从 GitHub 找到的相近项目，作为玩法信息组织和交互风格参考。

| 项目 | 相近点 | 本项目借鉴的设计思路 |
|---|---|---|
| [Ares](https://github.com/okn1ce/Ares) · [在线示例](https://okn1ce.github.io/Ares/) | 锻造题材的增量养成，资源面板、制作列表、升级和研究 | 常驻资源状态、配方选择、制作前显示成本 |
| [Idle Blacksmith](https://github.com/BloodyVerrick/Idle-Blacksmith) | 采矿、锻造、铁匠养成的浏览器游戏 | 把锻造与探索、养成分成清楚的功能页面 |
| [Block UI](https://github.com/malilion/BlockUI) | 制作面板、物品格子、角色状态、成就及响应式游戏组件；仓库标注 MIT | 品质色、物品格子、清晰选中状态、手机底部功能栏 |

本项目采用原创的「灰烬镇 · 炉火与星光」视觉：深炭灰底色、铜金操作区、低饱和品质色，以及石砌剑炉场景。插画、武器图、界面图标、CSS 和交互均在本项目中重新实现，没有拷贝上述仓库的代码或游戏素材。

视觉资产 `web/assets/forge.svg` 与页面中的武器、图标都是 SVG，不依赖外部图片、在线字体或 CDN。即使断网，游戏界面仍然可用。
