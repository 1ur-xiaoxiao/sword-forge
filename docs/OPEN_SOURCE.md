库随 Windows EXE 和安卓 APK 一起内置，游戏中无需联网。旅程设置的“开源组件与作者”包含完整许可证入口；源码压缩包也包含完整许可。

## 这次落地的玩法闭环

准备武器与药水 → 进入某个已解锁地区的三层秘境 → 探索宝箱/泉水 → 普通战斗和精英战斗 → 选择锋锐/复苏/丰收祝福 → 进入新布局的下一层 → 通关获得材料、金币、幸运符、保护符 → 返回工坊打造更强武器。

- 入口一次消耗 20 体力；本次房间战斗不再重复扣体力。
- 宝箱、泉水、每个战斗房间每层只能领取一次。
- 祝福本次秘境有效，每种只选一次，可组合三种；全部拥有后精英不再弹出选择。
- 击败本层守卫和精英才能下楼。秘境精英不会冒充六域首领并领取首通战功。
- 撤离保留已到手收获；战败按原规则损失 10% 金币、返回营地，祝福与未完成楼层结束。
- 种子、楼层、已领取房间、祝福和战斗回合保存在 C 的 V4 存档中；走路位置与可见地图是界面辅助数据，按旅程与种子隔离存储。

## 学习者从哪里继续扩展

1. 在 `src/delve.c` 修改房间奖励、入口消耗、楼层难度和三层礼包。
2. 在 `src/adventure.c` 修改战斗中的祝福效果。
3. 在 `web/dungeon.js` 修改地板/墙壁绘图、镜头与地图参数。
4. 在 `web/app.js` 的 `renderDelve` 修改房间交互文字；有新数值时在 `src/game_api.c` 添加 JSON 字段。
5. 增加保存字段必须同时修改 `src/save.c` 的读写与 `game_validate`，保留旧版本兼容。
