# 剑炉物语：C 语言单机概率锻造游戏

一个中文控制台小游戏。探索打怪获取材料和金币，锻造不同品质的剑，装备和强化武器，提升角色及锻造师等级，逐步挑战更高区域。终极目标是打造 **传说级王座圣刃 +10**，达成后仍可继续游玩。

使用 C11 编写，无联网功能，无第三方游戏库。项目已经包含 Windows 可执行文件，源码分模块存放，适合学习结构体、数组、函数、随机数和文件读写。

## 1. 直接开始玩

在本机打开 `D:\c语言\概率游戏`，双击 **`start.bat`**。

1. 第一次启动自动创建角色和新手礼包。
2. 在菜单输入数字，然后按 Enter。
3. 输入 `0` 保存并退出。
4. 下次启动输入 `1` 继续存档。

现成程序位于 `build/forge_game.exe`。通过 `start.bat` 启动可保证工作目录正确，让存档始终写进项目的 `saves` 文件夹。如果可执行文件被删除，启动脚本会先编译。

本机已找到 GCC：`D:\mingw64\bin\gcc.exe`。这个路径只是编译器回退位置；换电脑后也可以把自己的 GCC 的 `bin` 目录加入 PATH，无需改源码。

## 2. 第一次建议这样玩

1. 输入 `3` 查看新手背包：180 金币、12 铁矿、6 硬木、3 药水、1 幸运符、1 保护符，以及一把已装备的普通铁剑。
2. 输入 `2`，选择 `1` 旅人铁剑，选择是否使用幸运符。程序会先显示**本次实际概率**，再让你确认花材料锻造。
3. 获得更强武器后立即装备；也可以在菜单 `4` 里装备。
4. 输入 `1` 探索，再选 `1` 林间矿道。战斗中输入 `1` 攻击；生命不足时输入 `3` 喝药。
5. 体力或生命不足，回营地输入 `6` 休息一天，免费恢复生命和体力。
6. 角色到 3 级解锁灵晶区域和配方，6 级解锁陨星区域和配方，10 级解锁最终配方。

你可以不断探索、锻造、强化与回收。战败不会丢失武器，只损失当前金币的 10%（向下取整），并回营地恢复半血。

| 数字 | 功能 |
|---|---|
| 1 | 探索：选择区域，进入回合战斗，胜利获得资源 |
| 2 | 锻造：选择配方、幸运符，查看概率后确认 |
| 3 | 查看材料、道具、全部武器和装备状态 |
| 4 | 装备、强化、回收武器 |
| 5 | 商店：购买药水、幸运符、保护符 |
| 6 | 免费休息一天，回满生命和体力 |
| 7 | 在营地使用药水 |
| 8 | 查看一次性成长里程碑 |
| 9 | 手动保存 |
| 10 | 读取磁盘存档，失败时保留当前角色 |

操作武器时使用列表左侧的**序号**，不是 `#` 后的唯一编号。当前装备的武器不可回收；先装备另一把再回收。

## 4. 基础数值和概率

### 角色和锻造师

- 角色等级 1～20，生命上限 = `100 + (等级 - 1) × 12`。
- 角色基础攻击 = `6 + (等级 - 1) × 3`，总攻击还要加上已装备武器攻击。
- 角色升级所需经验 = `40 + (当前等级 - 1) × 25`。
- 锻造师等级 1～10，升级所需经验 = `30 + (当前等级 - 1) × 20`。
- 探索胜利获得角色经验；每次锻造获得 8 角色经验和 `12 + 品质编号 × 4` 锻造经验。
- 每次强化尝试获得 2 角色经验和 6 锻造经验。角色升级时回满生命。
- 等级达到上限后，该项经验归零；体力最高 100，武器背包最多 80 把，资源数量上限 1,000,000。

### 配方和基础品质概率

以下为锻造师 1 级、未使用幸运符、未触发保底时的概率。每次锻造必定产出一把武器，随机决定品质；材料不足或背包满则不开始锻造，也不扣资源。

| 配方 | 角色等级 | 金币 | 铁矿/硬木/灵晶/星陨石 | 普通 | 精良 | 稀有 | 史诗 | 传说 |
|---|---:|---:|---|---:|---:|---:|---:|---:|
| 旅人铁剑 | 1 | 30 | 4 / 2 / 0 / 0 | 55% | 28% | 13% | 3.5% | 0.5% |
| 灵晶长剑 | 3 | 90 | 6 / 3 / 2 / 0 | 30% | 35% | 25% | 8.5% | 1.5% |
| 星陨重剑 | 6 | 180 | 8 / 4 / 3 / 1 | 10% | 30% | 38% | 18% | 4% |
| 王座圣刃 | 10 | 320 | 12 / 6 / 5 / 3 | 0% | 15% | 45% | 32% | 8% |

概率内部使用整数权重，总和为 10,000，精度为 0.01%。

- 锻造师每提升 1 级，把 0.5 个百分点的低品质概率移向高品质。
- 使用 1 张幸运符，再转移 12 个百分点。先从普通扣，再从精良扣。
- 转移的权重中，50% 给稀有、35% 给史诗，其余给传说；整数舍入的尾数归传说。
- 例如新手铁剑用幸运符后为：普通 43%、精良 28%、稀有 19%、史诗 7.7%、传说 2.3%。
- 连续 19 次没有史诗或传说，第 20 次至少史诗；获得史诗或传说后计数清零。保底跨配方共享，低品质的所有概率移到史诗，传说概率保留。
- **角色等级解锁配方，锻造师等级提升概率**，这是两套成长系统。

武器基础攻击 = `配方基础攻击 + 品质编号 × 9 + 随机 0～5`。四种配方的基础攻击分别为 10、18、27、40；品质编号从普通的 0 到传说的 4。

### 强化和道具

- 武器最高 +10，每级强化增加 `3 + 品质编号` 攻击。
- 当前强化等级为 `u` 时，成功率 = `min(100, 95 - u × 7 + (锻造师等级 - 1) × 2)`%。
- 单次金币成本 = `20 + u × 15 + 品质编号 × 10`；铁矿成本 = `2 + u / 2`，整数除法向下取整。
- 失败下降 1 级，最低 +0，武器不会消失。保护符可阻止失败降级；选用后无论成功或失败均消耗 1 张。
- 治疗药水：20 金币，恢复 55 生命，不超过上限；满血使用不扣药水、不消耗战斗回合。
- 幸运符：65 金币，单次锻造提升品质概率。
- 保护符：90 金币，单次强化保护等级。
- 回收未装备武器获得 `2 + 品质编号` 铁矿，以及 `10 + 品质编号 × 12 + 强化等级 × 4` 金币。

### 探索和战斗

| 地区 | 等级门槛 | 体力 | 敌人生命 | 敌人基础攻击 | 基础金币 | 经验 | 主要材料 |
|---|---:|---:|---|---|---:|---:|---|
| 林间矿道 | 1 | 15 | 45～60 | 8～11 | 45 | 24 | 铁矿、硬木；20% 额外灵晶 |
| 灵晶遗迹 | 3 | 22 | 100～115 | 16～19 | 90 | 45 | 铁矿、硬木、灵晶；15% 额外星陨石 |
| 陨星深渊 | 6 | 30 | 210～225 | 27～30 | 170 | 80 | 铁矿、硬木、灵晶、星陨石 |

进入时扣体力。胜利的金币在基础值上额外随机加 0～20；三个区域都有 18% 概率掉药水、8% 概率掉幸运符。高等级区域提供更多铁矿；具体掉落公式在 `src/adventure.c`。

- 攻击：总攻击再加随机 0～6，12% 概率暴击造成双倍伤害。
- 防御反击：攻击伤害减半，承受伤害约为三分之一；除法向上取整。
- 喝药：回血后敌人仍会攻击；药水不足和满血时不消耗回合。
- 逃跑：每次 75% 成功率；失败时敌人攻击，成功无战利品，体力不返还。
- 敌人每次攻击在基础攻击上再加随机 0～4。
- 休息无金币成本，无强制等待，适合轻量离线养成。

### 一次性成长奖励

| 条件 | 奖励 |
|---|---|
| 累计锻造 5 次 | 100 金币 + 2 幸运符 |
| 累计探索胜利 10 次 | 200 金币 + 2 星陨石 |
| 获得至少一把史诗或传说武器 | 180 金币 + 2 保护符 |

菜单操作结束后自动检查并发奖；每项只领取一次，领取状态写入存档。

## 5. 保存和读档

默认存档：`saves/game.sav`，为带版本号的文本格式。保存角色、经验、金币、生命、体力、材料、道具、武器、装备序号、保底、里程碑和随机数状态。

- 每次主菜单操作结束自动保存；退出也会保存。
- 先写 `game.sav.tmp`，写入成功后才替换正式文件，避免直接清空旧存档。
- 读档先解析到临时结构体，验证数量、数值范围、武器编号、版本号、结束标记等，全部通过后才更新当前角色。
- 截断文件、过大数字、非法背包数量和未知版本会被拒绝。损坏存档不会自动开始新游戏，需要玩家选择是否覆盖。
- 随机数状态也保存，因此同一存档后的同样操作会得到同样结果。
- 战斗只能在营地菜单保存；突然关闭窗口会回到最近一次菜单存档。通过菜单退出是最稳妥的方式。
- 可在关闭游戏后自行复制 `saves/game.sav` 备份。只支持同时运行一个游戏进程，避免两个窗口写同一个存档。

## 6. 修改源码后重新编译

双击 `build.bat`，成功后再双击 `start.bat`。修改源码后需要主动重新编译，启动脚本只会在程序不存在时编译。

也可以在 PowerShell 中运行：

```powershell
Set-Location 'D:\c语言\概率游戏'
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\build\forge_game.exe
```

构建脚本使用 C11，并启用 `-Wall -Wextra -Wpedantic -Werror -Wformat=2`，将警告视为编译错误。C 源码保存为 UTF-8；游戏运行时设置 Windows 控制台为 UTF-8。

### VS Code

1. 用 VS Code 打开整个 `D:\c语言\概率游戏` 文件夹。
2. 在集成终端运行上面的编译和启动命令，即可游玩。
3. 按 Ctrl+Shift+B 使用预置构建任务，带调试信息编译。
4. 若要 F5 单步调试，安装 Microsoft C/C++ 扩展，并确认 `D:/mingw64/bin/gdb.exe` 存在；其他位置请修改 `.vscode/launch.json` 的 `miDebuggerPath`。
5. 可以先在 `main.c` 的 `game_init` 调用或 `forge.c` 的 `forge_weapon` 函数中打断点。

终端编译和程序运行已实际验证；VS Code 的 F5 图形界面操作需在你的 VS Code 中执行。

### 可选 CMake 构建

```powershell
Set-Location 'D:\c语言\概率游戏'
cmake -S . -B build/cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build/cmake
ctest --test-dir build/cmake --output-on-failure
.\build\cmake\forge_game.exe
```

也可以使用支持 C11 的其他编译器。源码对 Windows 的控制台编码和文件替换作了条件编译；主要交付和验证平台为 Windows + MinGW GCC。

## 7. 验证方法

双击 **`test.bat`**，或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
.\build\forge_game.exe --demo
```

预期看到 **`12 test groups passed.`**。`--demo` 是固定种子的实际锻造与战斗演示，不修改玩家存档。

测试覆盖概率总和和保底、5,000 次实际锻造、资源不足不扣费、装备回收后的下标、强化保护、资源上限、战斗、一次性奖励、存档覆盖与损坏拒绝，还模拟从新手装备成长到 10 级解锁最终配方。测试存档写在 `build` 中并自动清理，不碰 `saves/game.sav`。

实际交付的编译、运行结果见 `VERIFICATION.md`。

## 8. 项目结构与学习路线

```text
概率游戏/
├─ README.md                  中文说明、玩法、数值、启动步骤
├─ VERIFICATION.md            实际验证记录
├─ start.bat / build.bat      双击启动 / 重编译
├─ test.bat / build.ps1       验证 / 构建脚本
├─ CMakeLists.txt             可选 CMake 构建
├─ include/
│  ├─ game.h                  数据结构、上限、核心函数声明
│  └─ ui.h                    菜单函数声明
├─ src/
│  ├─ main.c                  程序入口、菜单、自动存档
│  ├─ data.c                  配方、概率表、区域表
│  ├─ game.c                  初始化、随机数、成长、背包、奖励
│  ├─ forge.c                 锻造、保底、强化
│  ├─ adventure.c             回合战斗和随机掉落
│  ├─ save.c                  文本保存、解析、数据校验
│  └─ ui.c                    中文输入输出与交互菜单
├─ tests/test_game.c          自动验收
├─ .vscode/                  构建与调试配置
├─ build/                    已编译游戏及测试程序
└─ saves/                    玩家存档，首次运行时生成
```

按运行顺序读源码更容易：

1. **`game.h`**：认识 `Game` 和 `Weapon`。材料数量存在 `materials[]`，所有武器存在 `weapons[]`，`equipped` 是数组下标。
2. **`main.c → game_init()`**：程序创建一个 `Game g`，初始化金币、材料和新手剑；若有有效存档，则用存档继续。
3. **`ui_number()`**：读取一行文字，用 `strtol` 转为整数，拒绝字母、越界数字和超长输入。
4. **`ui_forge() → forge_weapon()`**：先检查资源，再扣资源，再产生随机品质，最后把新剑放入 `weapons[weapon_count]` 并增加数量。
5. **`battle_begin() → battle_step()`**：用 `Battle` 保存敌人的生命，玩家每选一次有效动作就推进一回合。
6. **`game_add_xp()`**：使用 `while` 处理一次经验带来的多次升级。
7. **`save_game() / load_game()`**：学习文件、临时结构体和先验证再替换的顺序。

例如选择铁剑且不用幸运符时，材料从铁矿 12、硬木 6 变成铁矿 8、硬木 4；金币 180 变成 150，背包武器从 1 把变成 2 把。品质影响新剑攻击，但不改变这次配方成本。你可以打断点直接观察这些字段。

先修改 `data.c` 中铁剑的基础攻击或概率，重新编译并执行测试，观察结果。接着尝试增加锻造动画、任务种类或武器名称。若要增加材料、品质、配方或字段，还需要同步修改数组上限、界面、存档格式和测试；不要只改一个数字就认为所有功能都兼容。

后续可以保持这些核心 C 函数不变，再给它们接入图形界面。当前版本的重点是可运行、易读、完整的养成循环。
