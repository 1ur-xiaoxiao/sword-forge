# 完整玩法 · 剑炉物语 3.1

这是一个可用鼠标、键盘与触屏操作的 Windows / Android 离线单机锻造养成游戏。C11 处理成长、随机数、战斗与存档；本地 HTML/CSS/JavaScript 显示中文界面。

## 3.1 的新增玩法与界面

- **2D 工坊**：点击地面或使用 WASD / 方向键行走，点击锻造砧、升级台、荒野之门互动；也提供同名按钮。
- **锻造与升级动画**：熔炉、落锤、火花、立体铁砧和符文台座；史诗紫光、传说金光与放射光束，颜色跟随 C 的实际品质。背包中“前往升级台”打开强化台，确认后才花费资源；成功、失败和保护符分别有反馈。
- **音效默认开启**：第一次点击/触碰后启用声音。顶部扬声器可关闭，选择会记住。
- **四段独立旅程**：右上角设置选择存档位，空位创建新角色；切换前保存当前进度，启动时恢复上次使用的旅程。旧 `game.sav` 是旅程 1。
- **批量回收**：背包点击“批量选择回收”，勾选任意武器或选择当前筛选结果，确认后回收；排序不会改变选择，装备中的剑不能加入回收。
- **同屏战斗**：双方角色、生命数值、血条、技能和药水在战斗面板内；手机战斗时收起六域地图，减少上下翻找。
- **三层随机秘境**：荒野探索的地区详情点击“进入三层随机秘境”。每次新探险/下楼生成新地图，房间相连，带自动寻路、视野迷雾、摄像机和小地图。电脑/手机均可行走。

秘境一次消耗 20 体力。每层宝箱与泉水各使用一次；普通守卫和精英被击败后才能下楼。精英提供锋锐（攻击 +25%）、复苏（胜利回血 25）、丰收（战斗金币 +25%）三选一祝福，三层可组合三种祝福。每层奖励金币和地区材料；三层通关额外获得金币、2 幸运符、1 保护符与星陨石。撤离保留已到手的物品，结束本次楼层与祝福。

**开源代码已经融合**：地图生成、A* 寻路和视野使用 [rot.js](https://github.com/ondras/rot.js) 的实际代码，完整许可证内置游戏；融合位置、固定提交、学习扩展说明见 [开源记录](OPEN_SOURCE.md)。数值与房间奖励仍由 C 负责。

## 安卓手机安装

已提供 **`outputs/剑炉物语-安卓版.apk`**，发到安卓手机点击安装即可离线玩，不需要连接电脑。最低Android8.0，包含ARM64与ARM32版本，采用手机本机存档。返回键、后台保存、触控布局和横竖屏已适配，并在Android16模拟器中实际验证。

具体安装、更新及重新编译见 [安卓说明](../android/README.md)。PC与手机存档独立，没有自动同步。

## Windows双击即玩

在 `D:\c语言\概率游戏` 下双击 **`剑炉物语.exe`**。

- 网页、样式、脚本和剑炉插画已经嵌入 EXE，可把这个文件单独复制到别的可写文件夹运行。
- EXE 自动启动本机游戏服务并打开独立游戏窗口，没有终端操作，也不需要编译器、Node、Python或联网。
- 使用电脑已安装的 Edge 显示窗口；没有 Edge 时使用默认浏览器。这是浏览器显示的桌面游戏，EXE 没有内置另一份浏览器。
- 根目录 EXE 继续读取原来的 `saves/game.sav`。单独复制 EXE 到其他文件夹会创建新的 `saves` 文件夹；搬家时一并带上 `saves` 才能继续原进度。
- `启动游戏.vbs`、`start.bat` 和 `build/sword_forge.exe` 仍可启动源码开发版。不要直接打开 HTML 文件。

第一次开始送新手剑、180 金币、12 铁矿、6 硬木、3 治疗药水、1 幸运符、1 保护符和1 体力药水。

## 四种探索事件

| 事件 | 选择一 | 选择二 |
|---|---|---|
| 封存宝箱 | 当地特色材料 | 金币 |
| 林间清泉 | 恢复45生命 | 恢复15体力 |
| 古代铸剑祭坛 | 角色经验 | 锻造师经验 |
| 流浪药师 | 25金币购买1体力药水 | 免费领取硬木 |

材料、金币和经验奖励随地区加深。所有事件至少有一个免费选项。未完成事件时不能继续冒险、休息或操作装备；先在探索页选择奖励。事件、已采集次数和地区战绩都自动存档，刷新或重启不会刷新事件奖励。

采集和事件保留连胜。体力不足又不想战斗时，可以先补体力再采集；需要金币和解锁目标时优先巡逻。

## 战斗选择

- **攻击**：全额武器攻击，12%概率暴击。
- **破空斩**：确定造成双倍攻击伤害，使用后冷却3次有效行动。冷却时点击不会扣资源或推进回合。
- **防御反击**：造成约半额伤害，承受的敌方伤害降至约三分之一。
- **喝药**：恢复55生命，消耗1治疗药水和一个回合，敌人也会行动。
- **逃跑**：75%成功，成功重置连胜；失败仍承受攻击。

首领每第三回合发动双倍重击，界面在行动前显示蓄力预警。强装备可以抢先击杀，装备不足时用防御应对重击并准备治疗药水。药水不会抵消敌人回合，不能靠喝药无限拖延。战败损失10%金币，回营地恢复半血，保留武器、材料和地图进度。

## 体力与连胜

免费营地休息回满生命与100体力，进入下一天并重置连胜。35金币的体力药水恢复40体力并保留连胜，20金币的治疗药水恢复55生命；泉水事件也保留连胜。没有真实时间等待。

连续第1～5场胜利金币和经验加成分别为0%、10%、20%、30%、40%，之后保持40%；第三场起额外掉1铁矿。休息、战败或成功逃跑重置；有连胜时休息需要确认。所有地区胜利有8%概率掉落体力药水。

## 六种锻造配方

下表为锻造师1级、无幸运符、未触发保底时的概率。界面根据当前条件显示真实概率。

| 配方 | 角色等级 | 金币 | 铁矿/硬木/灵晶/星陨石 | 普通/精良/稀有/史诗/传说 |
|---|---:|---:|---|---|
| 旅人铁剑 | 1 | 30 | 4/2/0/0 | 55/28/13/3.5/0.5% |
| 灵晶长剑 | 3 | 90 | 6/3/2/0 | 30/35/25/8.5/1.5% |
| 星陨重剑 | 6 | 180 | 8/4/3/1 | 10/30/38/18/4% |
| 王座圣刃 | 10 | 320 | 12/6/5/3 | 0/15/45/32/8% |
| 霜月双刃 | 13 | 450 | 14/7/7/4 | 0/8/37/43/12% |
| 黎明神剑 | 16 | 620 | 18/8/9/6 | 0/0/35/49/16% |

每次锻造必得武器，连续19次没有史诗或传说时，第20次至少史诗。幸运符和锻造师等级把低品质概率转到高品质；最高配方没有普通/精良时，会从稀有转移到史诗/传说。

角色最高20级，锻造师最高10级，背包最多80把。武器强化最多+10，失败降低1级，最低+0；保护符保住失败等级，但无论成功失败均消耗。当前装备不能回收，旧剑可以回收用于继续锻造。原来的锻造5次、胜利10次、获得史诗三个里程碑继续有效，只领取一次。

建议开局先打造并装备好剑，再巡逻两次和挑战苔岩巨像；之后根据所需材料选择地图，做事件和强化，再挑战更高首领。

## 存档与升级兼容

每次有效操作自动保存。当前格式 V4 兼容 V1/V2/V3 旧存档，原角色、背包、金币、保底和已有地图进度保留。V1/V2 没有地图战功字段，沿用此前升级规则从0开始；V3 的六域战绩和事件保持原值。

- 根目录单文件版使用 EXE 同目录的 `saves/game.sav`，开发版使用项目的 `saves/game.sav`。
- 写临时文件后再替换，读档先校验；损坏存档不会被启动程序覆盖。
- 旅程 1 使用 `saves/game.sav`；旅程 2～4 使用 `saves/game.slot2.sav`～`game.slot4.sav`；`active-slot.txt` 记录当前旅程。搬家时复制整个 `saves` 文件夹。
- 设置中的“开启新旅程”只重置当前槽位，先备份当前槽位；其他三个旅程保持。旅程 1 的备份是 `game.before-new.sav`，其他为对应文件加 `.before-new.sav`。
- 事件与秘境选择会保存。秘境连同敌人血量、回合、技能冷却一起保存，重启后继续战斗；普通巡逻/六域首领遭遇沿用当前服务内状态，服务重启后结束遭遇，保留已消耗的体力与生命。
- 设置里的「保存退出」结束服务。直接关闭窗口后两分钟没有请求自动结束。同一端口的多个窗口共用角色。
- 更新 EXE 时关闭游戏，将新版文件放回原位置，保留 `saves` 文件夹。

## 修改与重新编译

```text
include/game.h         固定数组、地区/事件/战斗数据结构
src/data.c             地区、敌人、首领和配方数值
src/game.c             成长、道具、背包、永久战功、校验
src/adventure.c        地图门槛、采集事件、技能与首领战斗
src/forge.c            随机锻造、保底与强化
src/delve.c            三层秘境、单次房间奖励、祝福与撤离
src/save.c             V1/V2/V3/V4兼容读档与原子保存
src/web_server.c       Windows图形入口、本机HTTP与资源读取
src/assets.rc          嵌入EXE的界面文件与版本信息
web/scene.js           原创 2D 工坊、品质揭晓、强化台和战斗
web/dungeon.js         秘境镜头、地板/墙壁、寻路和迷雾
web/vendor/            固定版本的 rot.js 与 BSD 许可证
web/                   两个平台共用界面
build.ps1              编译开发版和核心测试
package.ps1            构建包含所有界面资源的单文件EXE
tests/                 核心、HTTP和实际Edge浏览器验收
outputs/               EXE、截图和验证记录
```

开发机需要MinGW-w64，支持从PATH或 `D:\mingw64\bin` 查找GCC。PowerShell执行：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -Test
powershell -ExecutionPolicy Bypass -File package.ps1 -Test
```

第二条生成根目录 `剑炉物语.exe` 和 `outputs/剑炉物语.exe`，并把这一个EXE复制到临时目录执行接口测试，不依赖外部web文件夹。浏览器验收还需Playwright和Edge；运行游戏本身不需要它们。测试使用独立临时存档，不改玩家存档。

具体实际检查见 `VERIFICATION.md`，GitHub风格参考见 `docs/UI_REFERENCES.md`。工坊、人物、武器和场景图形为原创；秘境算法复用 rot.js，具体来源与许可证见 `docs/OPEN_SOURCE.md`。

CMake还提供 `sword_forge_portable` 单文件目标。若使用MinGW Makefiles，请在英文路径构建该项目；本机中文路径优先使用上面的PowerShell脚本。

验收入口：`tests/scene_check.cjs` 检查真实史诗/传说光效、升级台、批量回收、多存档与手机血条；`tests/dungeon_check.cjs` 检查 150 个地图种子、实际角色寻路、跨重启秘境战斗与奖励。测试要先构建 EXE；`build.ps1 -Test` 同时生成 `build/visual_fixture.exe` 视觉测试夹具，仅用于独立测试存档，不向正式游戏添加指定品质接口。
